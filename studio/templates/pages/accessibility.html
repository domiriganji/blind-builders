Accessibility

This site is built for screen reader users first. We aim to meet WCAG 2.2 level AA on every page.

What we test

  • Every page is checked automatically for labels, headings, link and button names, language and zoom.
  • Pages work with JavaScript turned off.
  • Nothing streams or updates by itself while you are reading. The one exception is the page that waits for slow AI work: with JavaScript on, it checks by itself, says the current step, plays three short taps when the work is done and moves you to a link to the result. You can turn the taps off on that page.

What we know is not perfect yet

Some screen reader and browser combinations have not been tested by people yet. If something does not work for you, please tell us in Ask the community and say which screen reader, browser and device you use.
