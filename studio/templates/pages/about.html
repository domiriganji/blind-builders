How this site works

{{ site_name }} is a website where blind and low-vision people build their ideas with AI: websites and apps, writing and publishing, research, and tasks done for them on the web.

Built around how you work

  • Every page works without JavaScript, on cheap phones and slow connections.
  • Each page has one main heading that says where you are or what just happened. Use your screen reader's heading keys to move around.
  • Slow AI work runs in the background. You get a page that says what is happening, and a "Check again" link. If JavaScript is on, the page checks by itself, plays three short taps when the work is done, and moves you to the result.
  • Sounds use rhythm, not pitch, so they work with hearing loss and can be felt as vibration.

Help comes from the community

There is no phone line. Members answer each other's questions in Ask the community, check each other's work in Peer checks, and share guides in Learn.
