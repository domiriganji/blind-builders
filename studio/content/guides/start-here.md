## Your first steps

1. [Create an account](/register). Right after, the site shows you a recovery code, spelled out one character at a time. Save it: the site sends no emails, so this code is the only way back in if you forget your password.
2. Connect your Claude API key on [Your Claude API key](/account/ai-key). An API key is a private code from Anthropic, the company that makes the AI. It lets this site use the AI and send the bill to you. [Getting your Claude API key, step by step](/learn/claude-api-key) goes through every step. If this site offers its own AI, [How paying works](/pricing) says so, and you can skip this step.
3. Try [Build](/build), or read [Your first website with Build, step by step](/learn/first-website) first.

## The short version

- Every page has one main heading that says where you are or what just happened. Jump to it first.
- Each page puts the summary first and the details after, under headings.
- Slow AI work happens on a job page. It has a "Check again" link. If JavaScript is on, it checks by itself, and when the work is done your focus moves to a link to the result.
- Before the AI builds something new or does a task for you, it reads back what it understood. You correct it or tell it to go ahead.
- Help comes from other members in [Ask the community](/help). There is no phone line.

## Moving around a page

Every page here has the same parts, in the same order:

1. A "Skip to main content" link. It is the first thing the Tab key reaches.
2. The site's name (a link to the home page), a "Menu: all sections" link that takes you to the list of sections, and the links to your account.
3. The main content. It starts with the page's only level 1 heading.
4. The list of sections, in a navigation region called "Sections".
5. A footer with links to how the site works, how paying works, accessibility and Ask the community.

The fastest way around is by headings:

- NVDA and JAWS on Windows: in browse mode, press H for the next heading, Shift+H for the previous one, and 1 to jump to the level 1 heading.
- VoiceOver on a Mac: press VO+Command+H for the next heading.
- VoiceOver on an iPhone: turn the rotor to Headings, then swipe down for the next heading.
- TalkBack on Android: set the reading controls to Headings, then swipe down for the next heading.
- With a braille display: the same heading keys work from your keyboard, and many displays have their own keys for them.
- With a magnifier, large text or zoom: every page has the same order, and the main heading comes soon after the top of the page. Pages never scroll sideways, so you only move up and down.
- With voice control: say "click" and the words you see on a link or button, for example "click Ask a question". If several have the same words, say "show numbers" and then the number.

The level 1 heading always matches the page title your screen reader gives when the page loads. The page title is the page's name, a comma, then Blind Creators Studio, for example "Ask the community, Blind Creators Studio". If a form needs a second look, the page title starts with "Please check" and the number of answers to check, and a list of them comes first. Each item in the list is a link that takes you to the field.

## When the AI is working: the job page

AI work can take from half a minute to a few minutes. Instead of making you wait on a page that changes while you read it, the site gives you a job page.

- Its heading starts with "Working on it", followed by what is being done.
- It says how long ago the work started and what the current step is.
- It has a "Check again" link. Activate it to see if the work is done. When it is done, the link takes you straight to the result.
- You can leave the page. Everything you started is listed in [Your recent work](/jobs).

If JavaScript is on, the job page also checks by itself every few seconds. When the work is done, it plays three short taps and moves your focus to a link that starts with "Done. Open the result". The taps are a rhythm on one note, not a tune, so you do not need to tell pitches apart. If you cannot hear the taps, the focus move alone tells you: the link appears on your braille display or screen. To turn the taps off, uncheck "Play three short taps when it is done" on the job page. The site remembers that choice in this browser.

Nothing streams. The answer appears whole, so it never talks over your speech or moves under your braille display.

If the work does not finish, the heading starts with "This did not finish", followed by the reason in plain words, and a link to go back and try again. Your work so far is kept.

## Read-backs: the AI checks with you first

Before the AI builds something new or does a task for you, it tells you what it understood: a read-back. Check it before you tell the AI to go ahead.

- If it is right, tell it to go ahead.
- If something is wrong or missing, correct it in your own words. It reads back again.

When you ask for a change to something already built, there is no read-back: the AI makes the change, and the result page tells you what changed.

The AI never silently changes your words. When it suggests a change to something you wrote, it shows your words and its suggestion, and you accept or reject each change.

Every result also says what was checked, how it was checked, and what nobody has checked yet. Text written by the AI is always labelled as written by the AI.

## Paying for the AI

- **Your own Claude API key.** Connect it on [Your Claude API key](/account/ai-key). The AI then runs on your key and you pay Anthropic directly. This site charges nothing for it. The site stores your key encrypted and never shows it again in full: only its last 4 characters, so you can tell which key it is.
- **The site's own AI.** This site may also let members use its own key: free for members, paid for by the site's owner, or with credits, which cost the AI's price plus a share that pays for running the site. [How paying works](/pricing) says which of these this site offers today, with the exact price.

If you have no way to pay set up, the page tells you plainly, and the AI does not run.

Only ever paste an API key on [Your Claude API key](/account/ai-key). Never put one in a question, an answer or a message to the AI.

## Where to get help

You lead the work, the AI does what you ask, and members help each other. There is no phone line or support staff.

- [Ask the community](/help): ask a question and members answer when they can. While you wait, you can ask the AI for a suggested answer. It is labelled "Suggested by the AI. Not checked by a member."
- [Peer checks](/checks): ask blind and low-vision members to test your website or app with their own screen reader, braille display or magnifier.
- The other guides on the [Learn and help](/learn) page.

When you ask a question, say which screen reader, braille display or magnifier, browser and device you use. The question form fills these in from your profile, and you can change them. Please leave out passwords, one-time codes, card numbers and API keys: everyone can read the community pages.

If you get stuck with anything in this guide, [ask a question about this guide](/help/ask?title=Start%20here%3A%20using%20this%20site%20with%20a%20screen%20reader).
