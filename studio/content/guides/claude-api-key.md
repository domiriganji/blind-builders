## The short version

1. Go to the Claude Console at [platform.claude.com](https://platform.claude.com/), and sign in or create an account.
2. Add money: Settings, then Billing, then "Buy credits".
3. Create a key: Settings, then API keys, then "Create key". The key starts with `sk-ant-`.
4. Copy it straight away. The Console shows the whole key only once.
5. Paste it on [Your Claude API key](/account/ai-key) and choose "Check and save my key".

## What an API key is

An API key is a private code from Anthropic, the company that makes Claude, the AI this site uses. When you connect your key, this site uses the AI for you and Anthropic sends the bill to you. This site adds nothing to Anthropic's price. [How paying works](/pricing) gives typical costs for each kind of task.

Anyone who has your key can spend your money. Treat it like a password: paste it only on [Your Claude API key](/account/ai-key), never in a question, an answer, a message to the AI or an email.

The button and menu names below come from Anthropic's own pages: [Get your Claude API key](https://platform.claude.com/docs/en/get-api-key) and [How do I pay for my Claude API usage?](https://support.claude.com/en/articles/8977456-how-do-i-pay-for-my-claude-api-usage). Nobody on this site has tested the Claude Console with a screen reader. If a name is different when you get there, ask a question about this guide (the link is at the end), and members can help.

## Step 1: create an account in the Claude Console

1. Go to [platform.claude.com](https://platform.claude.com/). Older pages call it the Anthropic Console, at console.anthropic.com.
2. Sign in, or create an account.

A paid Claude app plan is billed separately from the API. Some plans, such as Max and Team, include monthly API credits; others do not ([Anthropic: paying separately for the API](https://support.claude.com/en/articles/9876003-i-subscribe-to-a-paid-claude-ai-plan-why-do-i-have-to-pay-separately-for-api-usage-on-console)).

## Step 2: add money

The Claude API is paid for in advance with credits bought from Anthropic. These are separate from any credits this site may offer.

1. Go to Settings, then Billing, or open [platform.claude.com/settings/billing](https://platform.claude.com/settings/billing).
2. Choose "Buy credits" and follow the payment steps. You type your card details on Anthropic's page, never on this site.
3. Auto-reload is optional. It buys more credits when your balance falls below an amount you choose. With it off, the AI stops when your credits run out, until you buy more.

## Step 3: create the key

1. Go to Settings, then API keys, or open [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys).
2. Choose "Create key".
3. Give it a name you will recognise later, for example the name of this site.
4. Choose when it expires, and set "Linked account" to yourself.
5. Create it. The Console now shows the whole key, which starts with `sk-ant-`. It shows it only this once.

## Step 4: copy the key

Copy the key before you leave the page. If you lose it, you cannot see it again: create a new key instead.

- **On a computer:** if there is a Copy button next to the key, use it. If not, select the key text and copy it with Ctrl+C, or Command+C on a Mac.
- **On an iPhone with VoiceOver:** if there is a Copy button, double-tap it. If not, select the key with the rotor's Text Selection setting, then choose Copy from the edit menu.
- **On Android with TalkBack:** if there is a Copy button, double-tap it. If not, open TalkBack's menu (the gesture depends on your phone and TalkBack version) and use its editing actions to select the text and copy it.

To keep a copy, paste the key into your password manager. Do not keep it in an ordinary note or email.

If copying on a phone does not work for you, try a computer if you have one.

## Step 5: paste it here

1. Open [Your Claude API key](/account/ai-key).
2. Move to the "Claude API key" box and paste: Ctrl+V on Windows, Command+V on a Mac, or Paste from the edit menu on a phone.
3. The box hides what you paste, like a password box. If your browser runs JavaScript, tick "Show the key, to check what you pasted", under the box.
4. Choose "Check and save my key". The site checks the key with Anthropic before it saves it. If Anthropic does not accept it, nothing is saved and the page says so. Copy the key again, or create a new one.

After that, the site shows only the key's last 4 characters, so you can tell which key it is. On the same page you can choose which Claude model the AI uses with your key.

## If something goes wrong

- **You lost the key:** create a new key in the Console, then connect the new one here.
- **You shared the key by mistake:** in the Console, go to Settings, then API keys, and delete it straight away. Then create a new key and connect it here.
- **You want to stop using it here:** on [Your Claude API key](/account/ai-key), choose "Remove my key". To stop it working anywhere, also delete it in the Console.

If you get stuck at any step, [ask a question about this guide](/help/ask?title=Getting%20your%20Claude%20API%20key%2C%20step%20by%20step).
